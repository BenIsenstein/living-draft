# 01: Open a static Living Draft artifact

**What to build:** A user or agent can create and open one portable React TSX artifact through a generated Astro runtime, see updates during development, and build static output without shipping React client code.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] A minimal workspace and `living-draft` CLI can create and open a static artifact.
- [ ] The artifact renders through Astro and updates through Vite HMR.
- [ ] A production build contains the rendered design but no React client runtime or hydration bundle.
- [ ] Typecheck and build pass.
