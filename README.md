# Living Draft

**Design in code, by conversation.**

Living Draft is a local-first agentic interface design environment. Agents compose real React and shadcn/ui components, people review the running design in Living Draft Studio, and the resulting artifact can move into a React SPA or render through Astro as static HTML without translating mockup syntax.

See [PLAN.md](./PLAN.md) for the agreed architecture and implementation roadmap.

## Status

Planning complete. Implementation has not started.
